# web

Front-end do Meu Controle Financeiro (Next.js 16, JavaScript, Tailwind).

```bash
cp .env.example .env.local   # API_URL do backend
npm install
npm run dev                  # http://localhost:3002 (o backend precisa estar rodando)
npm test                     # testes de lib/ (node --test)
```

Detalhes de arquitetura e regras em `../CLAUDE.md`.
